# ML 스터디

머신러닝과 소프트웨어 개발 기초를 함께 학습하는 스터디 프로젝트입니다. 이 문서는 스터디의 목적, 학습 범위, 참고 자료, 일정과 준비물을 안내합니다.

## 스터디의 목적

이 스터디는 각 주제를 조금이라도 먼저 접했거나 한두 번 더 공부한 학습자가 함께 배우고 설명하는 방식으로 진행합니다.

- **학습자에게:** 머신러닝을 소개하고 실용적인 활용 사례와 지적 호기심을 나눕니다. 각 단원에서는 “왜 이 기술을 사용하는가?”를 살펴보고, 기술을 적용하는 작은 프로젝트를 학습의 중심에 둡니다.
- **강의자에게:** 복습과 설명을 통해 이해와 기억을 다집니다.
- **모두에게:** 개인적 성장과 지적 교류를 나누고, 서로에게 긍정적인 영향을 주는 스터디를 만들어 갑니다.

## 커리큘럼과 참고 자료

세부 내용은 확정 과정에 있지만, 다음 세 축을 중심으로 진행할 예정입니다.

### 1. 학습 환경과 소프트웨어 개발 기초

첫 수업에서 개발 환경을 함께 준비합니다. VS Code, Jupyter Notebook, WSL 및 리눅스 터미널(macOS는 Unix 터미널), Git과 GitHub 등을 다룹니다.

소프트웨어 개발 기초에서는 자료구조, HTTP, JSON, API, SQL/데이터베이스를 살펴보고 필요에 따라 HTML과 JavaScript도 다룹니다. 각 기술의 필요성을 이해하고 후속 학습에 필요한 기초를 익히는 데 초점을 두며, 작은 개인 블로그 제작 과제를 포함할 예정입니다. 이 과정은 약 2~3주 동안 진행할 계획입니다.

### 2. 파이썬 기초 보충 수업

프로그래밍을 처음 접하는 학습자가 작은 프로젝트를 진행할 수 있도록 필요한 파이썬 기초를 익힙니다.

- 참고 강의: [점프 투 파이썬](https://wikidocs.net/book/1)

### 3. 머신러닝과 인공지능

2020년대 AI 혁명의 기술적 기반을 이해하고, “데이터로부터 패턴을 찾는다”는 머신러닝의 관점에서 학습합니다.

책 구매는 필수가 아닙니다. 다만 강의자는 아래 책을 핵심 자료로 사용할 예정이므로 자세한 설명과 이해를 원하는 분께는 구매를 권합니다. 구매한다면 최신 기술과 흐름이 반영된 신판(오랑우탄 표지)을 구판(도마뱀 표지)과 혼동하지 않도록 확인해 주세요.

- 참고 도서: [핸즈온 머신러닝 with 사이킷런, 파이토치](https://product.kyobobook.co.kr/detail/S000221505880)
- 더 자세한 학습 내용은 후속 안내를 참고해 주세요.

## 수업 일정과 준비물

메인 수업은 소프트웨어 개발 기초와 머신러닝을 중심으로 하고, 보충 수업에서는 파이썬 기초를 다룹니다.

- 메인 수업: 금요일 13:00~16:00
- 보충 수업: 일요일 13:00~16:00
- 첫 메인 수업: 10월 16일 금요일 13:00
- 첫 보충 수업: 10월 26일 월요일 오후 (마지막 시험 시간을 알려 주세요.) 이후에는 계획대로 매주 일요일에 진행합니다.

시간대와 수업 시간은 아직 확정되지 않았으며, 스터디를 진행하면서 필요에 따라 조정할 수 있습니다. 메인 수업과 보충 수업을 함께 들을 수 있도록 최대한 배려하고, 어느 한쪽의 부족함 때문에 다른 수업을 포기하는 일이 없도록 하겠습니다.

준비물은 다음과 같습니다.

- 노트북 또는 컴퓨터 (필수)
- 펜과 노트 (강력 추천)
- 『핸즈온 머신러닝』 (강력 추천)

## 함께 지켜갈 태도

서로 친하고 정이 두터운 사이더라도, 강의자는 시간과 노력을 들이고 참여자도 소중한 시간을 내어 함께합니다. 서로를 존중하고 성실하게 참여해 스터디가 오래 이어질 수 있도록 합시다.

서로 상처받는 일이 있더라도 개인적 성장과 지적 호기심, 서로에게 주는 긍정적인 영향을 되새기며 진지하게 임하고 솔직하게 이야기 나누길 바랍니다.
